# Fuente preservada de Feed Geológico

`original/` conserva el código del repositorio `henryconteron/feed-geologico` empleado durante la integración. Su actualizador global se mantiene como antecedente y no se ejecuta desde esta ubicación. El conjunto global de novedades no es la biblioteca curada.

La colección pública está en `data/library/studies.json` y `biblioteca.html`. La lección de observación de rocas se conserva en `original/cursos/observacion-rocas.html` con sus hojas de estilo.

No eliminar el repositorio remoto anterior hasta tener verificada su preservación y decidida la transición de sus enlaces.
