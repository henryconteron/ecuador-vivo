# Ecuador Vivo · Expedición anime andina · 13 de octubre de 2026

## Contrato aprobado

Referencia: `01-anime-andino.png` del tablero «Cinco direcciones visuales» aprobado por el usuario. Complemento: `04-dioramas-cientificos.png`, exclusivamente para ilustraciones explicativas. La interfaz debe ser real y conservar sus funciones; no una captura utilizada como interfaz.

- Web pública: navegación crema, texto azul tinta, portada panorámica ilustrada a sangre, titular serif blanco a la izquierda, acciones jade y crema. La ilustración no representa mediciones ni un mapa exacto. Accesos funcionales a mapas, historias, datos y fuentes; sin falsas cuentas o acciones de la maqueta.
- Inicio de producción: mismo paisaje y tipografía editorial; crear/abrir antes de los espacios de trabajo, proyectos reales conservados, ninguna miniatura pesada calculada al entrar.
- SIG: chrome azul tinta compacto, propiedades y referencia crema, jade en acciones/selección. Conservar ventanas flotantes, mapa científico, límites, control temporal y escalas originales.
- Studio: chrome azul tinta, canvas prioritario y herramientas compactas; ventanas móviles conservadas. El diseño de la interfaz no modifica escenas guardadas ni añade ilustraciones automáticamente a datos.
- Recursos: canvas, biblioteca y propiedades crema; cabecera tinta, jade seleccionado. Ilustraciones originales insertables como imágenes independientes con procedencia. Un diorama raster no se presenta como modelo 3D editable.

## Tokens

Tinta `#132B46`, cielo `#67BEE7`, jade `#238E77`, papel `#FFF5DF`, coral `#F27662`. Jade de texto/acciones `#176F5C` para contraste sobre crema. Serif local Lora para titulares; Atkinson Hyperlegible/Segoe UI para interfaz. Radios 4/8 px; píldoras solo en acciones de portada. Ritmo 4/8/12/16/24/32/48 px.

La paleta editorial nunca sustituye automáticamente la paleta de una variable científica. Ninguna interpolación, estadística, fuente, escala, fecha o geometría se modifica por este cambio visual.

## Estados y adaptación

Conservar vacío, cargando, error, selección, deshabilitado y guardado. Foco visible, etiquetas de controles y contraste AA. Móvil: portada apilada, titular legible, sin texto sobre el personaje; navegación desplazable y controles alcanzables. Preferencia de movimiento reducido respetada. Imágenes locales WebP, sin originales de varios MB en cada carga.

## Aceptación

1. Integración real en web, Inicio, SIG, Studio y Recursos.
2. Pruebas existentes de navegación, ventanas, proyectos y recursos sin regresiones.
3. Nuevas imágenes con procedencia y distinción ilustración/dato.
4. Comparación visual real a 390, 768 y 1440 px si el navegador lo permite. Si está bloqueado, registrar esa limitación, no afirmar fidelidad visual comprobada.
5. Sin publicar, borrar proyectos, migrar motores o subir a GitHub automáticamente.
